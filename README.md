# 3D 病毒互動探索百科 (3D Virus Exploration Lab)

專業、現代且高互動性的 3D 病毒形態學與醫學探索網站，基於 WebGL 與 Three.js 開發。

---

## 🌟 核心功能

### 1. 8 款熱門與經典病毒 3D 模型
1. **SARS-CoV-2 (新型冠狀病毒)**：S 刺突蛋白三聚體、脂質包膜、M/E 蛋白、內部 RNA 螺旋與 N 核蛋白。
2. **Mpox (猴痘病毒 / M痘)**：圓角磚狀外膜、表面小球體、兩側側體 (Lateral Bodies)、雙凹啞鈴形核心 (Dumbbell Core) 與雙鏈 DNA。
3. **Influenza A / H5N1 (甲型流感 / 禽流感)**：HA 血凝素與 NA 神經氨酸酶雙刺突、內部 8 條分節 RNA (vRNP)。
4. **Bacteriophage T4 (T4 噬菌體)**：二十面體頭部、壓縮 DNA 線圈、收縮尾鞘、六角基板與 6 條蜘蛛狀尾絲。
5. **Ebola Virus (埃博拉 / 伊波拉病毒)**：長絲狀牧羊杖 (6 字型) 形態、GP 糖蛋白棘突、內部全長螺旋核衣殼。
6. **Dengue Virus (登革熱病毒)**：90 個人字形 (Herringbone) E 蛋白二聚體緊密平滑二十面體、球形衣殼與正鏈 RNA。
7. **Rabies Virus (狂犬病毒)**：經典子彈型結構、平底內凹基座、G 糖蛋白與內部緊密盤繞 RNP 螺旋彈簧。
8. **HIV-1 (人類免疫缺陷病毒 / 愛滋病毒)**：gp120/gp41 刺突、富勒烯截角錐形衣殼 (Conical p24 Core)、雙拷貝 RNA 與逆轉錄酶。

### 2. 3D 自由互動操作
- **360° 自由軌道旋轉**：滑鼠左鍵或單指滑動。
- **平滑縮放 (Zoom In / Zoom Out)**：滑鼠滾輪或雙指縮放。
- **視野平移 (Pan)**：滑鼠右鍵或雙指平移。
- **視角預設快捷鈕**：正面視角、俯視頂部、側視圖、微距特寫、重置視角。
- **自動巡航自轉**：開關 360 度自動緩慢旋轉。

### 3. 三種深入檢視模式
- 🌐 **外觀全貌 (Surface Mode)**：擬真生物材質與表面刺突分佈。
- 🌓 **剖面透視 (Cutaway Mode)**：切開外殼，透視內部核酸 (RNA/DNA)、衣殼與酶系統。
- 🧊 **全息透光 (Hologram Mode)**：晶透發光與幾何晶格線框。

### 4. 3D 結構錨點標籤與導航
- 空間浮動標籤，點擊自動平滑運鏡特寫並展開專業醫學機理說明。

### 5. 雙病毒同屏比對模式 (Comparison Mode)
- 任意選擇兩種病毒進行同屏 3D 旋轉比對，具備**真實奈米比例 (nm scale)**、傳播力 (R0)、致死率與受體比對。

### 6. 生醫 HUD 數據儀表板 & 高解析截圖
- 顆粒直徑 (nm)、基因組型、宿主受體、潛伏期、傳播途徑、臨床疫苗與抗病毒藥物。
- 支援一鍵匯出高畫質 3D 截圖 (HD PNG)。
- 內建 Web Audio API 科幻生物實驗室音效（可自由開關靜音）。

## 🚀 快速啟動方式

### 方法一：直接點擊開啟
直接使用任何現代瀏覽器（Google Chrome、Microsoft Edge、Firefox、Safari）開啟 `index.html` 即可使用。

### 方法二：透過本機 Web 伺服器
1. 雙擊執行 `start.bat`。
2. 瀏覽器將自動開啟：`http://localhost:8899/index.html`
